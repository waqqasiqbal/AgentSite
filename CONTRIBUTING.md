# Contributing to AgentSite

AgentSite is exploring a new application boundary, so proposals should make the trust model clearer, not only add more autonomy.

Before opening a pull request:

- explain the user or company problem being solved;
- identify whether the change is read-only or causes side effects;
- document permissions, approval requirements, inputs, outputs, and failure modes;
- include tests or an evaluation plan for agent behavior;
- avoid adding secrets, private data, or provider-specific assumptions to the core protocol.

For large design changes, open an issue first so the protocol, runtime, and security implications can be discussed openly.
