# AgentSite Glossary

**AgentSite** — A company-hosted agent boundary that understands requests and can use approved capabilities to answer or act.

**Capability** — A named, typed, permissioned operation available to the agent.

**Adapter** — An implementation that connects a capability to an existing API, CLI, MCP server, database, or workflow.

**Action receipt** — A structured record of what the AgentSite proposed, authorized, executed, and returned.

**Consequential action** — An action that changes data, spends money, sends communication, changes access, or otherwise affects a person or organization.

**Agent-native interface** — An interface optimized for delegation of goals and completion of work rather than navigation through pages or commands.
